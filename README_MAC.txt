================================================================
  PIC-CLIP STUDIO PRO — macOS QUICK START GUIDE
================================================================

Welcome to PicClip Studio! This package runs natively on Apple Silicon 
(M1 / M2 / M3 / M4) and Intel Macs with local Metal GPU acceleration.

----------------------------------------------------------------
HOW TO RUN:
----------------------------------------------------------------
1. Double-click "PicClip.command".

2. On the first launch only:
   - It will automatically set up your local AI environment (~45s).
   - The native PicClip Studio window will open automatically.

3. Future launches:
   - Simply double-click "PicClip.command" — it will launch instantly!

----------------------------------------------------------------
FIRST-TIME MACOS PERMISSION NOTE:
----------------------------------------------------------------
If macOS shows: "PicClip.command cannot be opened because it is from an unidentified developer":
1. Right-click (or hold Control and click) "PicClip.command".
2. Select "Open".
3. Click "Open" on the confirmation dialog.
(You only have to do this once).

Alternatively, open Terminal in this folder and run:
chmod +x PicClip.command
